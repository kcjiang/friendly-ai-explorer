# 更新日志

## v0.5.0-beta.1 — 2026-10-29

发布测试版

- 优化知识库，统一 Markdown 文档管理与 AI 检索。
- 新增文件管理，支持公共与个人空间、文件共享及工单附件。
- 升级设备诊断工具，整合终端与控制台，提升连接稳定性并统一日志管理。

## v0.3.1-dev.3 — 2026-10-23

- 新增英文、简体中文界面，按浏览器首选语言判断；不支持的语言（含繁体中文）回退英文。
- 语言按钮位于主题按钮左侧，会话 Cookie 保持手动选择，不绑定账号，不改变 URL。
- 统一界面文案、日期日历、表单校验及系统错误消息；命令和技术缩写以英文为基础，业务原文和已保存的 AI 内容保持不变。
- AI 输出跟随界面语言，TODO 缓存按语言隔离，排队任务和定时配置保存语言快照。
- 更新全新初始化结构和英文种子数据；开发容器启动时同步锁文件依赖，修复依赖卷缺少 next-intl 导致的启动失败。
- 新版需重新初始化数据库，操作步骤见 [数据库部署说明](../deployment.md#database-initialization)。

## v0.2.5-dev.4 — 2026-10-20

- 数据维护采用统一 shadcn/ui Base 组件、Tailwind 4 主题和 Geist 字体；支持图标标签页、列选择、排序箭头、行选择统计及 30 条分页。
- 三类记录弹窗支持 768px 断点双列、窄屏单列；统一必填提示“请填写此字段。”，使用 Scroll Area 并保留完整焦点光圈；审计信息默认折叠为“编辑记录”。
- 增加业务多选、工程师账号 FAE、项目具体立项日期、产品项目指纹；固件地址可跳转，联系方式与指纹通过输入组右侧按钮复制。
- 客户级别、产品类型、项目经理、阶段和通讯工具由开发者在下拉框内维护；引用检查包含最近删除记录。
- 客户及产品持久化识别名称，重复名称按原名称、` (2)`、` (3)` 分配首个空缺；最近删除占号，彻底删除或改名释放名称，不重排其他记录。
- 修复国家搜索过滤模式、复制 Toast 层级和弹窗裁剪问题。
- 清理旧城市区域类型、预览中的无效联想请求及重复事务锁，统一命名写入的加锁顺序；更新数据维护文档，移除已失效的部署指引。
- 数据库改用单文件 `db/init.sql`，历史迁移不参与新部署。删除无人读取的旧数据库版本种子，应用版本由前后端版本文件统一维护。

### 部署说明

本版本采用新的数据库基线。更新 init.sql 不会自动清空已有库；按照 [数据库部署说明](../deployment.md#database-initialization) 先备份、停止应用和任务进程，再初始化并启动新版应用。重建会清除历史账号、业务记录和 AI 配置，恢复默认种子；上传文件不会随数据库重建删除。未在本次操作中发布镜像或更新服务器。

更早版本说明保留在 [应用内发布说明](../../frontend/src/config/release-notes.ts)，应用版本按钮可查看完整历史。
